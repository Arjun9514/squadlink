# SquadLink – SQL (MySQL) part
Schema, seed data, stored procedures, functions, triggers and nested queries.

- `DDL.sql` – tables, functions, procedures, triggers
- `DML.sql` – sample inserts/queries
- `reset_demo.sql` – restores seeded data after demos
- `SquadLink_backup.sql` – full database dump
- `stuff/schema.sql`, `stuff/data.sql` – alternate schema/seed scripts
- `screenshots/` – DDL/DML/procedure/function/trigger outputs

Run `DDL.sql` then `DML.sql` in MySQL. The frontend repo expects database `SquadLink`.
